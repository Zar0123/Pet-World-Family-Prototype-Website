Pet Shop Website Prototype

Instruction to Run:

1. Open the project folder in Visual Studio Code
2. Install the Live Server extension.
3. Right-click on 'index.html'.
4. Select "open with live server".

Important Notes:
- This website uses Javascript and LocalStorage.
- Features such as cart, login, and checkout require Liver Server to Function Properly.
- Opening the HTML files directly  (file://) may not work correctly.
